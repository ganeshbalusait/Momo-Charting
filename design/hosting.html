Corrected hosting

app.momox.io — one origin, no backend changes.

The earlier plan assumed :3001 served the app. It doesn't — it is API-only and bound to loopback. This routes the frontend and the API to one hostname at the tunnel instead, so nothing in api_server.py has to change and the backend never restarts.

Two local services, split by URL path at the tunnel:
Local
/api/*→127.0.0.1:3001 existing API — untouched, stays loopback-only
/*  (everything else)→127.0.0.1:4173 static build of frontend/dist — new, tiny
:5173—not exposed Vite dev server stays exactly as it is, local only
Why this shape: the API keeps binding to 127.0.0.1, so it is never directly reachable from the internet — only cloudflared, running on the same machine, can talk to it. You get one origin without a single line changed in api_server.py, and without a restart.
The one tradeoff: app.momox.io serves the built frontend/dist, so your edits appear there only after a vite build. Running vite build --watch keeps it current on save. Your :5173 workflow is completely unaffected.

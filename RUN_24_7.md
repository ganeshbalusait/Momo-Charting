# Run AgenticAI Trading Continuously on macOS

Use the production address: [http://localhost:3001](http://localhost:3001).

Port `5173` is only the temporary Vite development server. It stops when its Terminal process stops and is not the supervised 24/7 product URL. Both `localhost:3001` and `127.0.0.1:3001` are supported, but use `localhost:3001` as the normal bookmark.

## One-time automatic setup

```bash
cd "/Users/2320754846/Documents/AgenticAI-Trading 2/frontend"
pnpm run build

cd "/Users/2320754846/Documents/AgenticAI-Trading 2"
./scripts/install_macos_service.sh
```

The installer publishes a private production runtime under `~/Library/Application Support/AgenticAI-Trading`, installs a macOS LaunchAgent, starts it immediately, and verifies the health endpoint. The service restarts after a crash and starts again whenever this macOS user logs in.

## Start or restart it manually

Use this command when the service is already installed:

```bash
launchctl kickstart -k "gui/$(id -u)/com.agenticai.trading"
```

Check it:

```bash
launchctl print "gui/$(id -u)/com.agenticai.trading"
curl --fail http://localhost:3001/api/health
```

Open [http://localhost:3001](http://localhost:3001) after the health request succeeds. A full restart can take about one to two minutes on this project because the analytics services initialize before the web port opens.

## Run in the Terminal for debugging

First stop the supervised copy so port `3001` is free:

```bash
launchctl bootout "gui/$(id -u)" "$HOME/Library/LaunchAgents/com.agenticai.trading.plist"
```

Then run the project in the foreground:

```bash
cd "/Users/2320754846/Documents/AgenticAI-Trading 2"
./scripts/run_macos_production.sh
```

Keep that Terminal window open. Press `Control-C` to stop it. Reinstall and restart the automatic service afterward:

```bash
cd "/Users/2320754846/Documents/AgenticAI-Trading 2"
./scripts/install_macos_service.sh
```

## Logs

```bash
tail -f "$HOME/Library/Application Support/AgenticAI-Trading/app/artifacts/logs/production.error.log"
```

The Mac must remain powered on and connected to the internet. A LaunchAgent cannot run while the Mac is shut down, and it resumes after this user logs in again.
